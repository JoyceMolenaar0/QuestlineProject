# QuestlineProject
## 🎮 Demo-uitleg – Quest System

### De speler kan naar een NPC lopen en met R interacteren.
### Er opent een Quest-venster waarin je de quest kunt accepteren of weigeren.
### Wanneer de speler de quest accepteert, wordt deze toegevoegd aan de Quest Log, die je kunt openen met de Tab-toets.

## Er zijn drie soorten Objectives:

### Kill Objective – versla een bepaald aantal vijanden.
### Locatie Objective – bereik een specifieke plek in de wereld.
### Interact Objective – voer een actie uit met een object of persoon.

Telkens wanneer een objective voltooid wordt, verschijnt er een notificatie bovenaan het scherm met de melding “Objective Complete!”.
